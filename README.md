# salary-analysis-project
# 💼 Salary Analysis by Job Title

This project analyzes salary trends across different job titles in the data domain.

## 📊 Overview

The dataset contains job titles and associated salary ranges. Key metrics such as average minimum and maximum salaries were calculated to uncover trends.

### ✅ Job Titles Included:
- Data Scientist  
- Data Analyst  
- Data Engineer  
- Machine Learning Engineer

## 🔹 Summary Table

| Job Title                 | Count | Avg. Min Salary | Avg. Max Salary |
|--------------------------|-------|------------------|------------------|
| Data Scientist           | 455   | $113,321         | $150,709         |
| Data Analyst             | 47    | $95,478          | $142,042         |
| Data Engineer            | 47    | $96,784          | $133,510         |
| Machine Learning Engineer| 21    | $89,666          | $135,428         |

## 🔍 Key Insights

- **Data Scientists** dominate the dataset and earn the highest max average salary.
- **Data Analysts** and **Data Engineers** are equally represented but show varied salary ranges.
- **Machine Learning Engineers**, although fewer in number, still command high salary ceilings.
